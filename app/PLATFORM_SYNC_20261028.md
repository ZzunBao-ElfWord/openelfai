# Android / iOS 共用业务代码核对

## 本次范围

Android 和 iOS 均以本目录同一份 lib/ 与 pubspec.yaml 构建，不维护两套业务页面。公共信息流、分享面板与关闭重开修复、账号与社区页面、隐私政策与用户协议使用共享实现。

本次补充 Android/iOS 双平台回归测试，不复制两套页面，不覆盖旧工作区的未提交改动；前面已完成的修改继续保留。

## 明确保留的差异

- 不在本次对齐中调整收益、钻石充值和支付环境规则。
- iOS 的 API 充值继续保留网页充值提示，Android 原入口不变。
- Apple StoreKit / Android 支付宝 SDK、登录验证码方案、系统权限和分享回调保留各平台所需实现。
- 微信 iOS Universal Links 未验证的开关仍为 false，不能为表面一致强行开启；B站/快手等未完成接入的能力仍显示待接入。

## 验证

- Android 和 iOS 均验证公共信息流不依赖钱包初始化、相同公共内容接口、错误提示与注销后不回填旧响应。
- 分享在两端分别验证关闭、下拉划掉、复制链接、图片预览、外部回调未返回及迟到回调时重新打开。
- 完整客户端测试：113项通过，1项跳过。现有支付功能测试确认 iOS API充值限制、原钻石面板及平台分支仍保留。

这些是 Flutter 平台变体与模拟插件测试，不代表 Android/iPhone 真机或所有第三方SDK均验证通过。
