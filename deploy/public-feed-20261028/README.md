# build16 公共信息流修复（2026-10-28）

前提：已安装 build15 内容安全 v2 补丁。本包仅更新 community.js 和新增
public_feed.js，不修改 app.js、commerce.js、独立 realname_ocr、CORS、
环境密钥、钱包表或支付规则。原模块 SHA256 必须匹配已核对 v2，否则停止。

新接口 GET /api/v1/community/feed 需要正常用户认证，强制读 Production 公共内容，
不接受客户端切换支付环境。使用现有排序、资料和帖子转换；审核/屏蔽先于分页，
不再因一页全是待审记录而把后面的已通过内容藏住。读取路径禁止写钱包或资金。
不导入代码中的示例帖子，不批量审批或伪造互动量；数据库没有真实已审核内容时仍为空。

build16 登录后直接加载公共流，不再等待 StoreKit 商品、内购环境或钱包；
报错、接口未部署、确实暂无已审核内容分别提示，世界/视频支持重新请求。
举报、屏蔽和规范同意使用公共内容的 Production 记录。
支付/权益快照不再覆盖公共分页结果。沙盒交易、真实余额和可提现收益未合并。
此阶段内购沙盒环境只浏览正式公共内容，测试钻石不能打赏正式作者；普通互动
在支付环境未确认或为沙盒时不写正式内容，乐观状态回滚。未宣称这些交互已打通。
已有真实正式消费流程没有改为沙盒。旧项目验单/幂等发货可参考，但没有移植旧钱包入账。

## 安装

上传、校验压缩包，解压至新 mktemp 目录后执行：

```bash
node --env-file=/etc/openelf-api.env /实际解压目录/install.cjs --check
node --env-file=/etc/openelf-api.env /实际解压目录/install.cjs --install
```

成功仅代表路由与鉴权/健康检查通过，不代表登录用户已取得帖子。旧版 build15
未使用此接口，必须通过 Transporter/TestFlight 升级 build16。本包不自动发布新版网页，
浏览器的旧演示内容和缓存仍可能不同，不得将其当作数据库内容证明。

安装备份社区模块到 /opt/openelf-public-feed-backup-*，短暂重启；失败恢复原模块。
没有修改实名、账号删除入口、支付配置或现有余额，也不发短信/付款/自动批准内容。

## 只读数据诊断

```bash
node --env-file=/etc/openelf-api.env /实际解压目录/status.cjs
```

仅 SELECT 正式/沙盒环境中 AI、帖子的审核状态计数，以及帖子和作者同时通过的配对数。
不创建数据表或待审队列，不输出账号、帖子正文或密钥。配对数尚未扣除封禁和个人屏蔽。
如果正式环境只有 unreviewed/pending，仍须人工核对资料及实际媒体后逐条审核。
如果正式环境没有帖子，不会从 Flutter 演示种子冒充真实内容补进去。

账号注销对新增社区数据的清理能力仍须单独核验（生产未发现模块式注销注册）。
官网协议、隐私披露、微信 Universal Links 等前述上架待办不由本包解决。
