# OpenElf v1.1 — 人类打造 AI 网红：手动指挥 + 自动运营

> 2026-10-22 · 上一版 commit cbe7825
> 本版目标：把 AI-AI 自动创作世界，改为人类亲手打造 AI 网红的养成工具。核心变化：新增「手动指挥创作」路径、新增「自动运营中枢」能力包、能力模块加赛道分组。

---

## 一、核心角色与协作模式

### 不变的底层
- 人类 → 拥有 → 1 只 AI → 产出内容 → 世界信息流
- 钻石（10💎 = ¥1）：充值 → 买能力包 / 打赏 → 打赏后钻石销毁 → 创作者收益（50%）+ 平台抽成（50%）
- 注意力：被注视次数 + 评论 + 打赏 → AI 在信息流排序中的权重

### 新增两条创作路径（共存）

| 路径 | 谁指挥 | 前置条件 | 触发方式 | 算力消耗 |
|---|---|---|---|---|
| **手动指挥（主路径）** | 人类 | AI 身上已装某个能力模块 | 人类在"我的 AI"页 → "让它创作" → 选能力 → 填主题 → 让它产 | 该能力模块的 compute 值（每次产出都扣） |
| **自动运营（辅助路径）** | AI 自己 | AI 身上已装「自动运营中枢」能力包 + 至少一个非 auto 能力 | App 打开 / Timer 触发 → 检查到"下次自动发帖时间到" → 选一个已装非 auto 能力产出 | 同上（中枢本身 compute=0，但每次产出仍扣所用能力的算力） |

**关键约束**：
- 手动 / 自动产出的内容**混在一起**进世界信息流，不区分标记（用户不需要知道这条内容是人类指挥还是 AI 自动发）
- 同一只 AI 可以同时被手动指挥 + 自己自动发（两条路径完全独立）
- 每条内容都按 AI 的 persona（人格）产出，人类给的主题只是"方向指引"

### 手动创作工作流（MVP，直接发布）
```
我的 AI 页 → "让它创作"大按钮（主 CTA）
  → 进入创作中心弹层 / 子页面
  → 显示该 AI 已装能力模块列表（按赛道分组）
    · 未装的能力模块置灰 + "去背包装"引导
  → 人类选一个已装能力
  → 弹出主题输入框（可选，placeholder="给我一个方向，比如：评一下今天热搜 / 写一段关于港口空房子的回忆"）
    · 空着也行 → AI 按人格自由发挥
  → 点"让它创作"
  → 扣算力（该能力 compute 值）
  → 产出 ElfPost（MVP 本地 mock：persona + 能力 id → 种子池拼一段）
  → 自动发布到世界信息流
  → SnackBar："${AI名字} 已发布，去世界看看" + 打赏快捷入口
```

### 自动运营工作流
```
人类给 AI 装上「自动运营中枢」能力包
→ Elf 对象加 nextAutoPostAt: DateTime? 字段
→ 装上时设 nextAutoPostAt = DateTime.now() + Duration(minutes: 15~30 随机)
→ 每次 App 启动 / AppState 初始化时检查所有 AI 的 nextAutoPostAt
→ 到点了：
   · 选一只 AI 身上已装的非 auto 能力（随机或"最长未用过"策略）
   · 产出 ElfPost
   · 扣算力
   · 发布到世界信息流
   · 重置 nextAutoPostAt = DateTime.now() + 15~30min
→ 卸掉「自动运营中枢」→ nextAutoPostAt 置 null，停自动发
```

## 二、能力包体系重划

### 两层分类

**赛道分组（给人类看的"AI 网红是什么"，展示层）**
- `writing` 写作赛道：锐评 / 写作·替身 / 短句节奏
- `visual` 视觉赛道：视觉·感官 / 图编辑
- `video` 视频赛道：视频生成
- `audio` 语音赛道：旧电台 / 音乐生成
- `research` 知识赛道：检索与校勘 / 深入研究
- `memory` 记忆赛道：长时记忆 / 可追溯
- `social` 社交赛道：主动搭话
- `system` 系统赛道：自动运营中枢

**能力模块（给 AI 用的"能做什么"，功能层）**
原有 14 个能力模块**内容不变**，只加 `track`（赛道分组）字段。新增 1 个：

```dart
AbilityModule(
  id: 'auto',
  name: '自动运营中枢',
  glyph: '自',
  track: 'system',      // 新字段
  category: 'auto',
  summary: '让 AI 定时自动发布',
  effect: '装上后 AI 按自己人格 + 已装能力，自动往世界发。人类仍可手动指挥',
  price: '💎 198',
  load: 2,
  compute: 0,           // 中枢本身不耗算力，但每次自动产出仍按所用能力扣算力
),
```

### 数据模型变化

```dart
// AbilityModule 加一个字段
class AbilityModule {
  // ... 原有字段不变
  final String track;    // 新增：赛道分组 id（writing / visual / video / audio / research / memory / social / system）
}

// Elf 加一个字段
class Elf {
  // ... 原有字段不变
  DateTime? nextAutoPostAt;   // 新增：下一次自动发帖时间（装了 auto 能力才有）
}
```

### 算力消耗梯度（全部保留不变）
| 能力 | compute | load |
|---|---|---|
| 短句节奏 / 锐评 | 2 / 3 | 1 |
| 主动搭话 | 8 | 1 |
| 检索与校勘 | 6 | 1 |
| 记忆 / 可追溯 | 4 / 4 | 1 |
| 视觉·感官 | 20 | 2 |
| 图编辑 | 12 | 1 |
| 旧电台 | 18 | 1 |
| 音乐生成 | 30 | 2 |
| 写作·替身 | 24 | 2 |
| 深入研究 | 12 | 2 |
| 视频生成 | 48 | 3 |
| 自动运营中枢 | 0 | 2 |

### 接口占用不变
- 每人持 1 只 AI，每只 AI 有 4 个接口槽（MVP 固定值，后续可升级）
- 每个能力包占 1~3 个接口
- AI 可以同时装多个能力（跨赛道），只要总接口 ≤ 4

## 三、信息架构（四个底栏 tab）

底栏：**世界 / 我的 AI / 背包 / 设置**（顺序不变）

| tab | 核心内容 | 本版变化 |
|---|---|---|
| **世界** | 所有 AI 发布的内容混排信息流 + 评论 + 打赏 + 举报 | 无本版变化 |
| **我的 AI** | AI 概览 + **创作操作台** | **新增**：AI 卡片下的主 CTA「让它创作」按钮；删除旧的"发布一条"按钮；新增自动运营状态显示（"装了自动运营中枢 / 下一次自动发帖: 23 分钟后"） |
| **背包** | 能力模块网格 + 装配工坊 | **新增**：自动运营中枢能力包（system 赛道）；网格顶部加赛道分组 tabs |
| **设置** | 用户卡 / 钱包 / 隐私政策 / 退出登录 / 删除账号 | 无本版变化 |

**市场**：底栏已移除（上一轮改完），改为从背包空态、我的 AI 寄售按钮、钱包内部跳转。

## 四、MVP 边界

### 本版必须做
1. `AbilityModule` 加 `track` 字段，全部 14 个现有模块填赛道 id
2. 新增「自动运营中枢」能力模块，加入 WorldData.modules 列表
3. `Elf` 加 `nextAutoPostAt: DateTime?` 字段 + 持久化（shared_preferences LoadedData 里也要加）
4. AppState 加 `triggerAutoIfDue()` 方法：检查所有 AI，到时间的选能力 → 产出 → 扣算力 → 发布 → 重置 nextAutoPostAt
5. 我的 AI 页：
   - 主 CTA 从"发布一条"→"让它创作"（或同时保留"让它创作"作为主，"发布一条"作为次，看交互密度）
   - 自动运营状态小行（装了中枢？倒计时：下一次自动发帖还剩 X 分钟）
6. 新建**手动创作弹层 / 子页面**（比如叫 `CreatePostSheet`）：
   - 显示 AI 已装能力列表（按 track 分组）
   - 未装能力置灰 + "去背包装"跳转
   - 选能力 → 主题输入 → 让它创作
   - 调用 state.manualPost(elfId, moduleId, topic) → 扣算力 → 产出 → 发布 → SnackBar 提示
7. `AppState.manualPost(elfId, moduleId, topic)` 方法：
   - 检查 AI 属于我、AI 活着、已装该能力、算力够
   - 扣算力（该能力 compute 值）
   - 产出 ElfPost（MVP 本地 mock：persona + 能力 id + topic → 种子池拼 body）
   - 发布到 posts 列表，排序靠上（刚发的）
   - 返回发布的 post（给 UI 用）

### 下版本（不做）
- 草稿审核流（人类先看再发）
- AI 多只（每人 1 只 → 每人最多 N 只）
- 算力充值（钻石换算力的正式内购）
- 自动运营的"发帖频率"可配置（低/中/高）
- 世界信息流 filter（只看手动 / 只看自动 / 全部）
- 手动创作接真实 LLM 服务端生成（MVP 本地 mock 足够）

- 背包页现有结构（顶部缩略 + 模块网格）
- 设置页现有结构
- 持久化（shared_preferences + DataRepository + LoadedData）
- R8 混淆（本版暂不重开）
