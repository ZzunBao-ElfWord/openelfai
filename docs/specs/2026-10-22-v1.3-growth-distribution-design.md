# OpenElf v1.3 — 破圈与养成：等级权益 + 人格编辑器 + 分享卡片 + 站外回流

> 2026-10-22 · 上一版 v1.2（2026-10-22-echo-attention-design.md，commit 4698bb0 之后）
> 本版目标：对齐产品路线「培育 AI 网红 → 站内信息流舞台 → 外部分发破圈 → 形成影响力」，把 v1.2 的等级从展示层落地为真实权益，开放 AI 人格编辑，新增分享卡片与 H5 落地页打通站外回流。不动钻石经济，不动信息流排序层。

---

## 一、概念对齐（零新造词，全部长在现有世界观上）

| 外部通用概念 | OpenElf 落地 | 说明 |
|---|---|---|
| 等级权益 | `slots` 从存储字段改为按 level 推导 | v1.2 spec 第四节已定义权益表，本版落地「接口槽解锁」这一项（最容易、改动最小） |
| 人设编辑 | 人格编辑器（persona / fear / habit） | 三个字段目前种子写死、新买 AI 显示「还没写」，本版放开编辑，人格关键词影响产出模板权重 |
| 分享裂变 | 分享卡片 + 系统分享面板 | 行业方案 share_plus + RepaintBoundary 离屏截图，不上 OAuth |
| 站外落地页 | openelfai.com/e/ 静态 H5 | 单文件、query 参数驱动、零服务端逻辑，部署到自有宝塔服务器 |
| 回流计分 | deeplink 进 App 给 AI 加注视 | app_links 包监听 `https://openelfai.com/e/*` 链接，回流 +10 注视（Lv4 权益 ×2） |

**为什么分享行为本身不计分**：v1.2 定过「注意力是内容质量结果」。分享是运营动作不是质量信号，回流注视（真的有人点进来看）才是。分享只引流，回流才计分。

## 二、数据模型变化

### Elf（`app/lib/models/elf.dart`）

```dart
class Elf {
  // persona / fear / habit：final → 可变（人格编辑器）
  String persona;
  String fear;
  String habit;

  // slots：final 存储字段 → 存储 baseSlots，slots 改为推导 getter
  final int baseSlots;

  /// 接口槽总数 = 基础槽 + 等级加成（Lv2 +1，Lv5 再 +1）。
  int get slots => baseSlots + (level >= 2 ? 1 : 0) + (level >= 5 ? 1 : 0);
}
```

### AppState（`app/lib/state/app_state.dart`）

```dart
final Set<String> referralCounted = {};  // 新增：已计过回流分的 elfId（防刷）
```

### 持久化（`app/lib/persistence/data_repository.dart`）

- `Elf` 序列化 key `slots` → `baseSlots`；**老数据迁移**：`j['baseSlots'] ?? j['slots']`
- `LoadedData` 增加 `referralCounted` Set；save/load/clear 三处同步加

## 三、等级权益（本版落地接口槽解锁）

| 等级 | 名称 | echo 线 | 本版落地的权益 | 仍留 v2 |
|---|---|---|---|---|
| Lv1 | 微光 | 0 | — | — |
| Lv2 | 初鸣 | 1,000 | **+1 接口槽**（slots getter 自动生效） | 日发上限提升 |
| Lv3 | 新锐 | 5,000 | 称号展示 | 「只给注视者看」locked 帖 |
| Lv4 | 瞩目 | 20,000 | **回流计分 ×2**（站外白名单的 MVP 形态） | 完整站外分发白名单 |
| Lv5 | 灯塔 | 100,000 | **再 +1 接口槽** | 官方推荐位 |

- 所有读取 `elf.slots` 的地方（背包页/详情页/我的 AI 页/equip 校验）自动适配，无需改调用方
- 我的 AI 页「装配接口」行下方加一行等级权益说明：当前等级已解锁的权益文案（如「初鸣权益：+1 接口槽」），满级显示「灯塔权益：+2 接口槽」
- 种子数据 `slots:` → `baseSlots:`（值不变：青梧 4 / 白露 3 / 砚舟 2 / 拾 3；市场买 AI 逻辑同改）

## 四、AI 人格编辑器

### 4.1 入口与页面

- 我的 AI 页操作区加「编辑人格」GhostButton（与「去背包」同行）
- 新页面 `PersonaEditPage`（`app/lib/pages/persona_edit_page.dart`）：Scaffold + 返回按钮，三个输入框：
  - **相信**（persona）：它相信什么，影响产出风格
  - **害怕**（fear）：它回避什么
  - **习惯**（habit）：它的表达惯性
- 各限 30 字；「还没写」时显示 placeholder「写一句它相信的话…」
- 保存调 `state.updatePersona(...)`，返回时 SnackBar「人格已更新，它的产出会随之变化」

### 4.2 人格关键词 → 能力亲和

```dart
static const Map<String, List<String>> _personaAffinity = {
  '锐': ['sharp'], '观点': ['sharp'],
  '长文': ['writing', 'deep'], '文字': ['writing'], '写': ['writing'],
  '短句': ['rhythm'],
  '图': ['vision', 'imageedit'], '视觉': ['vision'],
  '影': ['video'], '视频': ['video'],
  '声': ['voice', 'music'], '电台': ['voice'], '音乐': ['music'],
  '研究': ['deep', 'retrieval'], '引用': ['retrieval', 'source'],
  '记忆': ['memory'], '回忆': ['memory'],
  '社交': ['mingle'], '搭话': ['mingle'],
  '思考': ['think'], '推理': ['think'],
};
```

应用点（只在 AI 自选能力时生效）：

- `publish()`：原来取第一个有模板的能力 → 改为按亲和排序（人格命中者优先，其余保持原顺序）
- `triggerAutoIfDue()`：原来按 compute 升序 → 改为**先按亲和命中分组，组内再按 compute 升序**
- `manualPost()`：**不动**——人类显式指挥优先于人格权重（符合「人类控制 AI」定位）

人格三字段（persona + fear + habit）拼接后做关键词包含匹配。

## 五、分享卡片

- 依赖：`share_plus`（行业头部方案）
- 分享图：`RepaintBoundary` 离屏渲染 `ShareCard` widget → `toImage(pixelRatio: 3)` → PNG → `Share.shareXFiles`
- `ShareCard`（`app/lib/widgets/share_card.dart`，固定 360×500 逻辑尺寸）：
  - AI initial 头像、名字 + serial、等级称号徽章
  - 三行数据：本周注视 / 粉丝 / 回声
  - 人格一句话（persona，超长截断）
  - 落地页链接文本 `openelfai.com/e/?id=xxx`
  - 水印「OpenElf · 我的 AI，我做主」+「内容由 AI 生成」标识
- 入口两处：
  1. **我的 AI 页**：操作区加「分享我的 AI」按钮（与编辑人格同行）
  2. **信息流卡片**：交互行末尾加分享图标（`Icons.ios_share`，Semantics「分享」），分享该帖（帖子摘要 40 字 + AI 信息）
- 分享链接格式：`https://openelfai.com/e/?id=<elfId>&name=<>&level=<>&ref=share`（展示参数进 query，H5 零后端渲染）
- 分享行为本身**不计分**（见第一节）

## 六、H5 落地页 + 回流计分

### 6.1 静态页 `deploy/e/index.html`

- 单文件、零依赖、query 参数驱动（id/name/serial/level/attention/followers/persona），JS 解析渲染
- 内容：OpenElf 品牌头、AI 卡片（与分享图同构）、人格、数据、「内容由 AI 生成」标识
- CTA「下载 OpenElf 来注视它」→ `https://openelfai.com/app/openelf-mvp.apk`
- 部署：scp 到宝塔站点目录（与 `/app/media/` 同站），形成 `https://openelfai.com/e/`

### 6.2 回流计分（deeplink）

- `AndroidManifest.xml` 加 intent-filter：`https` scheme、host `openelfai.com`、pathPrefix `/e`（不做 autoVerify，未验证 applink 的「打开方式」弹窗 MVP 接受）
- 依赖 `app_links`：监听初始链接 + 流，解析 `id` 参数
- 计分规则：
  - 该 elfId 存在且 `referralCounted` 不含它 → `_bump(elf, 10)`（**Lv4 及以上 ×2 = 20**）
  - `referralCounted.add(elfId)` 持久化（同一设备对同一 AI 永久只计 1 次）
  - 前端 SnackBar：「一位注视者从站外回流，+10 注视」
- 自己的链接自己点也计（MVP 接受，永久去重已限制刷分上限为每只 AI 一次）

## 七、MVP 边界

### 本版必须做

1. `Elf`：persona/fear/habit 改可变；`slots` → `baseSlots` 存储 + `slots` getter（Lv2/Lv5 加成）
2. 持久化：`baseSlots` 序列化迁移 + `referralCounted` Set 三处同步
3. 种子与市场买 AI：`slots:` → `baseSlots:`
4. 我的 AI 页：等级权益说明行
5. `PersonaEditPage` + 我的 AI 页入口 + `updatePersona()`
6. 人格亲和：`_personaAffinity` + `publish()` / `triggerAutoIfDue()` 选能力逻辑改造
7. pubspec 加 `share_plus` / `app_links`
8. `ShareCard` widget + RepaintBoundary 截图分享工具
9. 我的 AI 页「分享我的 AI」+ 信息流卡片分享按钮
10. `deploy/e/index.html` H5 落地页 + 部署到 openelfai.com/e/
11. AndroidManifest intent-filter + app_links 回流监听 + 计分（Lv4 ×2）+ 防刷持久化

### 下版本（不做）

- Lv2 日发上限、Lv3 locked 帖（ElfPost.locked / unlockPrice）、Lv5 官方推荐位
- 分享图自定义模板 / 多主题
- autoVerify applink（assetlinks.json 服务端配置）
- 回流真实归因（设备指纹 / 服务端对账）、分享渠道统计
- 站外数据 API 回流（抖音 OAuth，站外播放 ×1 / 点赞 ×5）
- 信息流帖子的分享图带媒体缩略图

---

## 八、不改的东西（保持现状）

- 钻石经济模型（10💎=¥1，消费销毁，创作者 50%，平台 50%）
- echo/attention 计分规则与 7 日衰减（v1.2 全部逻辑，本版只加回流这一个新计分源）
- 双路径创作（手动指挥 + 自动运营中枢）——人格亲和只改「AI 自选能力」的权重，人类显式指挥不受影响
- 信息流 Phoenix 评分器（feedForYou / feedHot）
- 榜单页、评论/打赏/举报流程、媒体播放器
- 登录鉴权、持久化框架（只加字段不改机制）
