# 桌面独立“对话”入口

按用户确认的方案，仅原生桌面宽屏左侧新增“对话”，顺序为对话、世界、视频、创建、发现、我。保留默认进入世界；桌面世界不再包含顶部工作台。原有工作台完整复用到 ConversationPage，不把既有创作派发改成另一套聊天接口，不新增定时任务/资料库。

既有页面索引保持0世界、1视频、2发现、3我；对话为附加页4，创建仍为独立路由动作。IndexedStack保留工作台状态，GlobalKey支持响应式布局切换时重挂载，单个工作台不会同时出现在世界和对话页。导航时取消焦点，避免隐藏输入框继续接收键盘。草稿、模式、技能选择为当前应用会话内状态，不承诺应用退出后的持久化。

独立对话页继续监听AppState，选择AI与账号恢复立即反映到工作台；短窗口纵向可滚动。侧栏导航/最近列表增加可滚动区域，账户入口仍在底部；桌面“马上开始”进入对话页。网页保留原有首页工作台，手机窄屏保留五格底栏，不改登录、充值、支付及上链配置。原生桌面缩到原有900px断点以下仍采用既有窄屏底栏，重新加宽后可返回左栏对话入口，输入保持。

验证：完整Flutter测试180通过、1跳过，静态分析没有error/warning（既有info仍在）。新增导航回归覆盖世界默认无工作台、唯一工作台实例、对话入口、草稿及运营模式保留、AI状态变化、窗口缩放、视频active状态、发现/我/创建路由、小屏原布局。独立Windows release编译通过，保留此前已成功登录的测试版。构建工具仍提示临时目录可能影响增量构建，不是构建失败。
