# Windows 单实例启动

截图中的多个窗口包括此前不同目录的旧版、登录修复版和对话预览版。新源码此前没有单实例限制；保留多份测试程序不代表应同时运行。

Windows入口在COM/插件/Flutter初始化前创建会话范围命名mutex，句柄保持到进程退出；重复启动只恢复/激活已有窗口并退出，不创建第二套Flutter引擎、自动任务计时器或会话。多个新版目录使用同一对象名称，不按exe路径分别上锁。主窗口设置识别属性；冷启动并发等待主窗口就绪，不能因为第一次尚未出首帧就再开一个引擎。

旧程序兼容：枚举同桌面Flutter主窗口，属性优先，否则同时核对标题OpenElf及进程名openelf.exe；新版会唤回已运行旧版。并发启动器可转交给已可见的旧版。此机制不能倒过来修改已经交付的旧exe：如果继续直接启动不含保护的旧exe，它仍可能多开。旧包保留备份，后续入口需使用新版。

激活尊重Windows前台限制，不强制置顶、不跨会话，不结束已有进程。原有https://openelfai.com/e/分享链接通过app_links既有WM_COPYDATA协议转交，UTF-8带终止符、长度限制与超时，不转交任意命令行参数。无磁盘锁文件，进程退出由Windows释放命名对象。

原生MSVC /W4 /WX测试通过：首次/第二/第三/重开、锁失败、跨进程互斥、无C++析构的进程退出释放、分享链接白名单及转交；新增Windows CI回归步骤。独立Windows release编译通过。Dart、登录/支付/导航业务代码未改。

用户选择保留当前一份对话预览窗口。实测并发启动新版3次，三个新进程均ExitCode=0退出，OpenElf总数保持1且原PID不变；未强制关闭、注销或重启用户会话。完整新版主实例应在用户手动关闭当前旧版后启动，不能把当前旧窗口称为已原地升级。
