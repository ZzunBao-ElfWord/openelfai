回退：服务端 `VIDEO_CDN_ENABLED=false` 仅停止 URL 转换，不关闭视频业务；客户端构建参数 `--dart-define=VIDEO_CDN_ENABLED=false` 仅停止本地 URL 转换。已存的源站地址不丢失。若服务器仍下发 CDN 地址，客户端开关不会强制反向改写服务器地址，完整回退需同时停用服务端转换。
